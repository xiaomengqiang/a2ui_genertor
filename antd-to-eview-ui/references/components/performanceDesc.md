# PerformanceDesc 性能说明

> 分类：其他

组件的复杂程度以及数据量，都会影响渲染性能及使用体验（react渲染机制决定）；请在以下数据规格内使用组件，以获得更好的用户体验。

### 规格说明

| 组件名称 | 属性名称 | 最大规格 |
|:-----|:-----|:-----|
| SelectPro | options | 500 |
| SearchInput | popItems  | 200 |
| DoubleSelect  | items   | 200 |
| MultipleSelect  | options | 500 |
| Select   | options | 500 |
