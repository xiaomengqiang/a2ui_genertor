# Table 表格使用规范

用于密集、可比较、基于行的企业数据。

## 使用规则

- 行内操作使用 `Button types=link`；状态使用文本、图标或 Tag，不使用 Badge。

## 布局

- 同一表格中的普通文字使用统一的文字色 Token；仅链接、状态、告警和禁用内容使用对应语义色，不得按列或行随意改变文字颜色。
- 选中行后在表格工具区显示已选数量和可执行操作。

## Don't

- 不要手动画分页、复选列、排序或筛选。
- 不要把标准表格行做成 Card。
- 不要用固定宽度破坏表格自适应。
- 不要使用开发组件不存在的属性或枚举值。
