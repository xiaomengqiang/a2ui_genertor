# TableRow
> Table row component. Container for cell components.
> id: string | component: "TableRow" | props: object | children: object

## props
- `expandedRowRender?`: SlotNode — Expanded content template. Renders with current row data context (use relative paths).

## children
类型: StaticChildren | TemplateChildren
> Cell components within the row. The order must match the order of columns defined in the parent Table.
